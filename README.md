🛍️ Pavão Semi Joias
📌 Sobre o projeto

O Pavão Semi Joias é um projeto desenvolvido com o objetivo de aprendizado, focado na criação de um e-commerce simples utilizando tecnologias básicas da web.


🎯 Intuito

Este projeto foi criado para praticar e entender melhor como estruturar e desenvolver um e-commerce, abordando conceitos como:

Estruturação de páginas
Estilização de layouts
Interatividade com JavaScript


🚀 Tecnologias utilizadas
HTML
CSS
JavaScript


💡 Objetivo de aprendizado

Durante o desenvolvimento, o foco foi:
Compreender a base do front-end
Criar uma interface de loja virtual
Simular funcionalidades comuns de e-commerce
